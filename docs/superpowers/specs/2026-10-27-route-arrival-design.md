# 路由阅卷落位

> 历史方案：已被同目录 `2026-10-27-route-unfolding-design.md` 替代，当前实现见 DESIGN.md 的“路由翻卷入页”。

用户已确认“阅卷落位”方案：每次进入路由以短青绿线和细卷标标识新页面就绪，约350ms，克制且不阻碍任务。

## 实现与边界

- 页头标题按 pathname 重建，立即显示，替换原有标题淡入/上移，避免额外等待。下方短线 scaleX 展开，卷标小幅落定；仅 transform/opacity，装饰 aria-hidden、pointer-events none、绝对定位不参与排版。
- 每次路径变化（包括返回）重播，搜索参数变化、输入及普通状态更新不重播。手机端缩短线长及卷标位移；系统减少动态效果时展示静态终态，运行期切换立即生效。
- 正文复用现有路由动画，位移4px、退出60ms、进入220ms，不新增遮罩、加载等待、循环、外部素材或依赖。懒加载、权限、焦点和业务状态保持现有约定。
- 正文与短线并行，不对内容逐块编排。快速连续导航由 React 卸载旧装饰，不保留定时器或监听器。

## 验证与实施顺序

1. 修改 Topbar、motion token 和局部 CSS；构建检查。
2. 桌面/手机正常动效回归：跨页、返回、同页输入/查询、运行期减少动态效果；保留截图及动画录像做实际页面审查。
3. 运行全部浏览器回归、测试类型检查和文档检查；代码复核后修复具体发现。
4. 同步 README、AGENTS、DESIGN、实施方案与交付说明，最后生成源程序清单，再提交推送并核对CI。
