# 统一 One Page 工作台设计

## 目标

所有受保护路由共用固定的页面外壳，只有当前工作面更新。1440×900、80%–200% 等效视口、720×450 矮屏与 375×812 手机均不得出现页面级纵向滚动。聊天正文、文档正文等不可安全分页的长内容允许在自己的固定窗口内滚动；常规配置、报告、结果和说明必须通过章节或页内分项切换呈现。

## 共用页架

- 新建 `WorkDeck`：统一章节栏、当前页标题、固定内容舞台与上一页/下一页。
- 桌面章节栏位于左侧；宽度不超过 900px 或高度不超过 600px 时转为紧凑网格，高度不超过 550px 的横屏转为单行。
- 每章按钮采用统一高度，活动标记使用 `layoutId` 在章节间平移。
- 章节内容采用方向感切换：前进从右侧 14px 进入、退回从左侧 14px 进入，旧页在 140ms 内向反方向 8px 退出，整体不超过 200ms；只改变 `transform` 与 `opacity`，正文不会先变成全透明。
- `prefers-reduced-motion` 下立即切换。切换后焦点留在同一章节按钮，内容区使用 `aria-live="polite"` 更新页面名称。
- 工作台容器使用 `min-height: 0` 与 `overflow: hidden`；固定高度只能由 CSS 视口推导，不写死桌面像素。

## 路由信息架构

| 路由 | 章节与布局 |
|---|---|
| 课题卷宗 | 概况、材料、归入、历史、体检、流程、边界；继续使用 `WorkDeck` 和页内分项 |
| 项目预审 | 运行与进度、结论、检查项、政策与查重、追问与边界；长报告不再整页向下堆叠 |
| 查重匹配 | 运行、查重结果、专家候选、回避边界、专家库；结果列表逐项翻页 |
| 智能问答 | 宽屏保持对话与证据双栏；窄屏用“问答 / 证据”章节切换；消息与证据只在各自区域内滚动 |
| 知识图谱 | 关键词图、人工图谱、实体与路径；中央画布固定高度，控制、搜索和详情不把页面撑高 |
| 文献趋势 | 图表、主题与文献、研判摘要；图表页固定两图，长列表单独翻页 |
| 文档中心 | 左目录、右书页；页面固定，目录、正文、文献表格各自在内容窗口内滚动或展开 |
| 用户管理 | 用户列表、新建用户、角色说明；桌面不再并排堆叠长表与表单 |
| 工作台 | 保持总览，只保留当前卷宗、核心指标和最多四项快捷入口，左侧导航是唯一功能入口 |

## 状态与交互

- 章节切换不重置业务状态。上传、流式回答、预审/匹配运行、文档读取和图谱选择继续使用现有请求序号与阻断规则。
- 查询参数只影响业务深链，不作为章节状态；章节状态保留在当前挂载周期。
- 移动端章节按钮、上一页/下一页和关键操作至少 44px。
- 任何自动切换不得在弹窗、抽屉或用户正在阅读其他内容时抢焦点。

## 验证

- 每个路由逐章检查 `documentElement.scrollHeight <= innerHeight + 1`。
- 检查活动内容面板 `scrollHeight <= clientHeight + 1`，聊天、文档正文和图谱画布按明确白名单豁免。
- 浏览器真实点击所有章节与分页，不只看 DOM 属性；验证抽屉关闭、焦点、键盘、减少动态效果和返回深链。
- 覆盖 1440×900、1920×1000、2560×1440、720×450、375×812，以及 80%–200% 等效视口。
- 保留截图与逐帧动画采样，确认方向、完播和内容不出现闪空帧。

## 迁移顺序

1. 共用 `WorkDeck` 与方向动画，卷宗迁移并作为样板。
2. 预审、查重匹配、文献趋势、用户管理迁移到章节页架。
3. 问答、知识图谱、文档中心固定工作区并统一切换动效。
4. 工作台压缩与全路由响应式收口。
5. 完整浏览器回归、实际页面审查、文档与软著清单同步。
