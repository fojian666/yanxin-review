# 浏览器回归设计

已确认方案：测试随项目交付，harness 仅调用统一命令，不绑定特定工具，不在每次保存文件时跑全套。

## 隔离与执行

Playwright 测试构建后的 React + 真实 FastAPI；每个用例启动独立临时数据库与回环随机端口，合成种子和公开政策快照离线导入。模型、嵌入、真实申请书种子和出网授权显式关闭，不读取开发库、不连接 8010。进程结束清理临时目录。浏览器阻止非本机 HTTP 请求。

## 覆盖与判定

覆盖四角色登录/退出/会话过期/越权、所有业务页面、上传校验/上传删除/CSV导入、离线流式问答/引用/跨页/错误恢复、真实预审与匹配及报告下载、旧请求竞态、趋势切换及无 WebGL 降级、空库、手机导航/焦点/窄屏换行、减少动态效果。真实流程走真实接口，网络故障及竞态测试明确标记受控响应。断言文档身份、权限、文件内容和业务边界，避免只测按钮可点击。

## 入口与证据

`npm run test:e2e` 构建并运行全套；`npm run test:e2e:smoke` 运行关键冒烟；CI 安装 Python/Node/Chromium 后执行相同命令。失败保留截图、视频、trace、服务器日志及去请求体的 API 状态摘要。HTML 报告只在本机或 CI artifact 查看，生成物均忽略，不提交会话、数据库、截图或上传件。

## 验收与边界

所有用例实际执行；桌面功能覆盖与 375px 手机专项通过；证明人为引入的受控故障能被检测并产生诊断附件；构建、现有 Python 回归、文档及源程序清单检查通过。首版使用 Chromium，不宣称覆盖 Safari/Firefox、真实大模型质量或生产负载。视觉审美仍由人工审查负责。
