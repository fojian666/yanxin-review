# 知识图谱与文档中心迁移设计

日期：2026-10-28  
状态：已确认并实施
来源：`/Users/chenguangxi/时空智能物联网系统`（完整版，只读）

## 1. 目标

把完整版“时空智能物联网系统”的知识图谱和文档中心页面呈现能力迁移到“江苏省自然资源科研诚信智慧治理平台”，同时保留本项目现有单页工作区、权限、检索、问答、预审、文档管理和人工复核边界。

本次不迁移物联网设备数据、课程文档正文或后端服务。迁移对象是页面的信息架构、组织方式、交互与动效；图谱内容根据本项目和新申报书重新生成，文档内容继续来自本项目文档库。

新申报书《新机制下储备补充耕地智能核验与动态监管关键技术研究》是图谱和文档中心的重点业务案例。其 DOCX 只作为本地资料使用，不进入 Git。

## 2. 已确认的产品决策

- 采用“并列入口”：新增一级功能“知识图谱”，现有“文档库”升级并更名为“文档中心”。
- 保留所有现行功能：文档上传、删除、筛选、问答、预审、索引状态、演示数据处理和文献 CSV 导入。
- 知识图谱由本项目生成，不复制完整版的物联网实体。
- 页面结构忠实借鉴完整版：图谱采用“左控制、中星图、右详情”；文档中心采用“左目录、右书页”。
- 视觉皮肤继续使用本项目的纸面、青绿、宋体和黑色界面体系，不照搬完整版的深空 HUD 色彩。
- 不修改完整版源项目。

## 3. 信息架构

单页工作区的功能顺序调整为：

1. 项目预审
2. 查重匹配
3. 智能问答
4. 知识图谱
5. 文献趋势
6. 文档中心
7. 用户管理（仅管理员）

新增路径为 `/graph`。现有 `/library` 保持为文档中心的深链，不破坏书签和浏览器返回；页面标题、侧栏和工作区标签统一显示“文档中心”。

## 4. 知识图谱

### 4.1 数据结构

首版图谱使用前端静态数据，放在独立的 `frontend/src/data/knowledge.ts`，不新增数据库表或图数据库依赖。

规模目标：48 个实体、100 条显式关系、7 个知识域。

| 知识域 | 实体数 | 代表实体 |
|---|---:|---|
| 科研全周期 | 8 | 江苏省自然资源科研诚信智慧治理平台、申报受理、立项评审、过程管理、结题验收、成果转化、评价指标、分级管控 |
| 诚信与合规 | 8 | 科研诚信、失信行为、学术不端、政策条款、合规审查、风险预警、信用分级、人工复核 |
| 评审与专家 | 7 | 形式审查、语义查重、专家画像、专家匹配、同单位回避、回避人员、负载均衡 |
| 知识与数据 | 7 | 申报书、政策库、文献库、专家库、成果库、知识图谱、RAG 知识引擎 |
| 模型与智能体 | 6 | 行业大模型、向量检索、证据链、风险预警 Agent、评审辅助 Agent、成果转化 Agent |
| 自然资源场景 | 8 | 储备补充耕地、占补平衡、项目—地块—指标、多时序遥感、耕地状态识别、谱系化样本、人机协同核查、监管闭环 |
| 安全与治理 | 4 | 内网部署、权限分级、审计追溯、数据脱敏 |

每个实体包含稳定 `id`、名称、知识域、说明、来源和可选属性。每条关系包含起点、终点和关系词。数据检验必须保证：

- 实体 ID 唯一。
- 关系端点都存在。
- 每个实体至少连接一条关系。
- 每个知识域都有实体。
- 最短路径只走显式关系。

### 4.2 页面结构

桌面宽屏采用三栏：

- 左栏：知识域筛选和最短关系路径。
- 中栏：全尺寸“语义星图”，包含搜索、类别图例、当前实体、推理路径和节点度数提示。
- 右栏：实体详情、属性、邻接关系、“从这里推理”和“让大模型解释”。

中栏的图谱沿用完整版的固定语义布局：根实体居中，各知识域形成稳定簇；节点大小由度数决定，支持平移和缩放。节点位置在模块加载时计算一次，筛选、搜索和换域不重新随机排布。

右栏是主要可访问交互入口。图中节点可点击，但所有实体和关系也必须能通过搜索结果与邻接关系列表用键盘访问。

### 4.3 交互

- 点击知识域切换显隐；至少保留一个知识域可见。
- 搜索实体名称、ID、说明和属性；命中项显示在画布上方，并高亮图中节点。
- 点击节点或搜索结果，更新右栏详情。
- 选择起点和终点后推演最短路径；路径节点与边在图中高亮，详情区同步显示路径链。
- “从这里推理”把当前实体设为路径起点。
- “让大模型解释”跳转到智能问答，并预填“请解释该实体在江苏省自然资源科研诚信智慧治理平台中的作用及关系”。
- `?focus=<id>` 深链直接定位实体；刷新和浏览器后退可恢复。

### 4.4 降级与无障碍

- `prefers-reduced-motion` 下关闭图谱过渡高亮，直接显示结果。
- 加载失败显示可重试错误态；空搜索显示明确空态。
- 图表带有文字摘要；筛选、路径和详情提供等价 DOM 控件。
- 窄屏 ≤1240px 时，中栏独占整行并给定稳定高度；左、右栏随后折成单列。手机先显示星图，再显示筛选和详情。

## 5. 文档中心

### 5.1 页面结构

文档中心复用 `/library` 路径，采用：

- 顶部工具栏：搜索、上传、移除演示数据、问答、预审和文献导入入口。
- 左侧目录：按申报书、政策、文献、资料/系统知识分组，显示当前文档和索引状态。
- 主阅读区：书页式正文、文档元信息、章节标题、表格/列表/提示块与页码。
- 底部翻页：上一篇/下一篇，以及当前页与总页数。
- 移动端：目录折叠为顶部按钮/选择器，选择后自动收起并保持正文焦点。

原有表格管理能力不删除。桌面在目录项提供当前文档操作，顶部提供全库操作；搜索后仍可完成上传、删除和跳转。文献 CSV 作为同级折叠区保留，不挤占阅读首页。

### 5.2 动态内容读取

文档中心不是静态迁移文档。新增只读接口：

`GET /api/documents/{doc_id}/content`

返回：

- 文档元信息：ID、名称、类型、年份、来源、状态、页数、文本块数。
- 按 `idx` 排序的文本块：页码、章节、正文。
- 不返回服务器文件路径或本地原始文件名。

接口要求已登录用户访问。文档不存在返回 404；文档存在但无文本块时返回空章节与明确提示，不返回 HTML。

前端 API 层新增 `documentContent(docId)`；`DocItem` 保持现有列表契约，不把全文塞进 `/api/documents`。

### 5.3 阅读与翻页

- 切换文档时，桌面宽度播放“开卷翻页”效果：旧页绕书脊旋转，新页即时可读，总时长约 620ms。
- 窄屏和减少动态效果时直接切换，不依赖完成回调显示正文。
- 文档正文保留可选择的文字；表格、页码和章节标签按结构化数据渲染。
- 每篇文档记录内部滚动位置，切换返回时恢复。
- 目录选中更新 `?doc=<id>`；刷新、深链和浏览器后退保持当前文档。

### 5.4 保留的现有能力

- 上传入口和上传弹窗。
- 文档名称筛选。
- 演示文档移除。
- 文档删除及确认。
- 从文档发起问答。
- 从文档发起预审。
- 索引状态和解析警告。
- 文献 CSV 导入、去重和演示文献移除。

## 6. 实现边界

- 不新增图数据库、Neo4j、Milvus 或外部服务依赖。
- 不让前端读取 DOCX 原文件；阅读内容只来自后端的已解析文本块。
- 不改变问答、预审、查重和专家匹配的业务规则。
- 不改变现有登录、角色权限和后端权限矩阵。
- 不把真实 DOCX、上传原件、解析全文或个人字段写入测试夹具或 Git。
- `.gitignore` 忽略 `*.docx`、`*.doc` 和 `.superpowers/`；`data/` 继续忽略本地上传与数据库。

## 8. 错误处理

- 图谱数据自身无效时显示页面级错误，不用空图伪装成功。
- 文档内容加载失败时保留目录和工具栏，主区显示错误与重试。
- 删除当前阅读文档后，选择下一条目录项并替换 URL；没有剩余文档时显示上传引导。
- 切换文档时旧请求使用请求序号作废，不允许晚到响应覆盖当前正文。
- 上传成功后刷新目录并定位新文档；失败保留原阅读状态。

## 9. 动效契约

- 图谱首次进入：页面标题、指标和三个面板按 32ms 错峰上浮；总时长不超过 620ms。
- 图谱节点高亮、搜索和路径推演只过渡颜色、线宽、透明度和 transform，不改变布局。
- 文档翻页只动 transform/opacity；正文切换在动画前完成，动画未完成也不能遮挡阅读。
- 移动端和 `prefers-reduced-motion` 直接切换。
- 所有装饰层 `pointer-events: none`，不拦截阅读、目录或工具栏操作。
