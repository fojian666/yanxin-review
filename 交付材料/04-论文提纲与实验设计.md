# 论文提纲与实验设计（初稿）

> 本文档为论文选题、结构和实验设计，不是已完成的论文；不得将本地演示数据写成正式实验结论。

## 一、选题方向

**候选题目 1**：面向自然资源科研管理的智能查重与专家匹配一体化方法研究  
**候选题目 2**：RAG 增强的科研诚信智能评审辅助系统设计与实现  
**候选题目 3**：科研诚信驱动的科研项目全周期智慧治理技术路径研究

建议优先题目 1，与考核指标“智能查重、专家匹配一体化工具”直接对应；如果论文更偏系统实现，可选题目 2。

## 二、摘要草稿（待实验后改写）

针对自然资源科研项目申报中人工查重效率低、改写识别弱、专家遴选主观、回避关系难核查等问题，提出一种智能查重与专家画像匹配一体化方法。方法以申报书为输入，构建结构感知分块和段落级相似度比对，结合专家研究方向、学科、代表成果、回避关系和评审负载进行约束过滤与可解释排序，并在统一工作台中输出证据与候选专家。原型系统采用 FastAPI + React 实现，支持 DOCX/PDF 解析、引用溯源和结果导出。实验将在真实历史本子、专家库和标注样本上评估查重精确率/召回率、专家匹配 nDCG、约束满足率和人工耗时。**（实验结果待补充）**

**关键词**：科研诚信；语义查重；专家匹配；检索增强生成；自然资源；科研管理

## 四、实验设计

### 4.1 数据

| 数据 | 规模（建议） | 来源/授权 |
|---|---|---|
| 历史申报书 | 50–100 份 | 省厅授权、脱敏 |
| 查重标注对 | 50–100 对 | 人工标注：抄袭/改写/合理引用/无关 |
| 专家库 | 100+ 位 | 现有专家库授权导入 |
| 专家匹配案例 | 20–30 个 | 历史抽取结果/专家人工判断 |
| 政策文件 | 30–50 份 | 现行有效版本 + 历史版本 |
| 公开成果 | 按需 | 论文/专利/标准/软著 |

### 4.2 基线

1. 字符级查重（传统）；
2. TF-IDF 段落查重（当前原型）；
3. 向量检索/混合检索（升级后）；
4. 专家匹配：仅关键词、仅语义、语义+约束（本文）。

### 4.3 指标

**查重**

- 精确率、召回率、F1；
- 误报率（合理引用被误判）；
- Top-k 命中率；
- 证据可读性/人工采纳率。

**专家匹配**

- 约束满足率（回避/负载/可用性）；
- nDCG@10、Recall@10；
- 与历史抽取结果/专家判断的一致率；
- 单位/方向多样性；
- 人工调整率。

**系统/业务**

- 单本查重+匹配耗时；
- 引用准确率；
- 人工预审耗时下降；
- 管理人员满意度。

### 4.4 消融实验

- 去掉结构分块 → 固定窗口；
- 去掉关键词/学科加权；
- 去掉回避/负载约束；
- 去掉相对匹配度/解释理由；
- RAG vs 无 RAG；
- TF-IDF vs 向量/混合检索。

### 4.5 案例与误差分析

- 改写/跨语言重复案例；
- 合理引用误报案例；
- 同单位/回避冲突案例；
- 专家画像缺失/成果不全案例；
- 大模型引用错误/幻觉案例。

## 五、伦理与合规

- 使用真实本子/专家数据前取得授权并脱敏；
- 不将评审材料用于模型训练（除非书面授权）；
- 专家匹配不使用性别、年龄等敏感属性；
- AI 结果只作辅助，不替代专家评审和行政审批；
- 论文中不出现可识别的申报人/专家个人信息。

## 八、最新指导下的候选扩展（2026-11-04）

原有查重与专家匹配方向继续保留。新增可讨论方向为“面向自然资源科研申报的证据可追溯智能预审方法”，覆盖材料完整性、政策依据检索、问题定位和补正核对；是否作为主论文，待获得样本与核实相关研究后决定，本节不主张学术新颖性已成立。

- 当前产品查重固定使用TF-IDF字面重合；前文语义查重、向量查重仅属于研究候选或对照实验，不能写成生产链路已采用，也不能将主题相近等同抄袭。
- 问答/政策检索可比较关键词、向量检索与有无引用约束；人工核对证据命中、引用支持程度、问题正确率和材料核对耗时。
- 按项目分组划分样本，同项目各版本及相似项目不能分散到开发集和最终测试集；历史时点问题只使用当时可获取的依据，避免新版本信息泄漏。
- 每年约60个立项项目仅是业务规模线索，不能作为实验样本量论证。先确认是否含未立项及补正项目，记录每类样本数量、缺失和授权；小样本结果报告分子分母与不确定性。
- 查重合理引用、政策缺证、扫描件不可读、缺单位导致回避未生效等负例单列；人工预审与系统辅助预审使用同一核对清单，记录时间及漏检/误报。
- 地域、单位分布可作为试点背景统计，不直接证明模型效果，也不作为科研诚信高低的推断依据。
