# 试点验证报告（本地验证初稿）

**课题**：科研诚信驱动的自然资源科研全周期智慧治理与大模型协同关键技术研究  
**验证对象**：科研诚信智能查重与专家匹配一体化工具 V1.0（原型）  
**验证日期**：2026-10-23  
**验证地点**：本地开发环境（非省厅处室试点）  
**报告状态**：初稿；数据包含合成演示数据，不能作为正式试点验收结论。

---

## 1. 验证目的

在真实省厅试点前，验证以下技术路径是否可跑通：

1. DOCX/PDF 申报材料能否解析、分块并保留引用位置；
2. RAG 问答能否基于上传资料给出带依据的回答；
3. 查重能否识别重复文档并给出段落级证据；
4. 专家库能否导入，匹配能否执行回避/负载约束并给出可解释理由；
5. 查重+专家匹配能否在同一任务中完成并导出；
6. 前端交互、3D 图表和动效是否稳定。

## 4. 结果分析

### 4.1 已证明可行

- 文档解析、分块、页码/章节引用链路可行；
- TF-IDF 段落查重能识别完全重复文档，并给出原文证据；
- 专家库 CSV 导入、回避/负载过滤、可解释匹配链路可行；
- 查重与专家匹配可以在同一任务中完成并导出；
- React + FastAPI 前后端分离、3D 图表和统一动效运行稳定。

### 4.2 不能据此得出的结论

- 不能据此计算查重精确率/召回率：当前只有少量重复样本，没有标注的“抄袭/改写/合理引用”测试集；
- 不能据此证明专家匹配质量：专家库为合成数据，没有真实评审专家和历史抽取结果；
- 不能据此证明业务提效：没有真实处室、真实本子和人工耗时对照；
- 不能据此证明政策条款级合规：当前政策库未接入；
- 不能据此证明生产可用：无 SSO/RBAC/等保/审计，未接现有系统。

### 4.3 发现的问题

| 问题 | 影响 | 处理建议 |
|---|---|---|
| 当前检索为字符 n-gram TF-IDF | 语义召回有限，改写/跨语言识别弱 | 升级 Qwen3-Embedding + Milvus + Reranker |
| 查重阈值未校准 | 可能误报/漏报 | 建标注对，校准 0.30/0.55 阈值 |
| 专家库为合成数据 | 匹配结果仅演示 | 导入真实专家库，补回避关系与历史评审数据 |
| 专家匹配分是启发式 | 绝对分数解释有限 | 用真实抽取结果做 nDCG/一致率校准 |
| 无 OCR | 扫描 PDF 无法解析 | 接 PaddleOCR / MinerU |
| 无 SSO/权限/审计 | 不能直接用于真实评审 | 接厅统一身份、RBAC、审计日志 |
| 与现有系统未联调 | 数据需手工上传 | 接只读 API/视图、预审结果回写 |

## 5. 正式试点方案（待执行）

### 5.1 试点范围

- 选取 1–2 个厅业务处室/批次；
- 20–30 份真实申报书；
- 3–5 位真实评审专家参与标注；
- 1 个政策文件包（含现行有效版本）；
- 历史本子/成果/专家数据按授权导入。

### 5.2 试点步骤

1. 数据授权与脱敏；
2. 建立黄金评测集（查重标注对、专家匹配案例、政策问答）；
3. 工具部署到内网测试环境；
4. 管理人员实际使用，记录耗时、采纳/修改情况；
5. 专家对匹配结果和预审报告评分；
6. 统计指标并形成正式试点报告。

### 5.3 正式试点指标（建议）

| 指标 | 目标（待试点校准） |
|---|---|
| 查重精确率/召回率 | ≥ 0.85 / ≥ 0.80 |
| 最高相似度证据可读率 | ≥ 90% |
| 专家匹配约束满足率 | 100% |
| 专家匹配 nDCG@10 | ≥ 0.80 |
| 单本预审耗时下降 | ≥ 50% |
| 预审报告人工采纳率 | ≥ 70% |
| 引用准确率 | ≥ 0.90 |

---

## 6. 结论

首期原型已跑通“文档解析 → 查重 → 专家匹配 → 结果导出”的技术链路，并验证了问答、预审、文献趋势等辅助能力。  
但本轮是**本地验证**，不是省厅试点；真实数据、真实专家、政策库、系统接口和正式指标尚未到位。下一步应按第 5 节开展正式试点，并补齐真实评测集。
