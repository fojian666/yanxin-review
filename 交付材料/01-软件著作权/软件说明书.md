# 科研诚信智能查重与专家匹配一体化工具 V1.9 软件说明书

> 软著申请材料初稿。著作权人、开发方式、完成日期、首次发表日期等信息以《申请信息表》及实际协议为准。

## 1. 软件概述

**软件全称**：科研诚信智能查重与专家匹配一体化工具  
**软件简称**：研信智评  
**版本号**：V1.9  
**软件类型**：科研管理辅助软件 / 人工智能应用软件  
**适用场景**：江苏省自然资源科研项目、科研课题的申报预审、语义查重、专家匹配和评审辅助。

本软件面向科研管理人员的“本子预审”场景：上传申报书后，软件对已入库文档做段落级查重，并从专家库中按研究方向、关键词、学科、回避关系、在研负载匹配候选专家，输出带证据和理由的辅助意见。

## 2. 运行环境

### 2.1 服务端

- 操作系统：Linux / macOS / Windows（原型验证环境为 macOS）；
- Python：3.10 及以上；
- Web 服务：FastAPI + Uvicorn；
- 数据库：SQLite（原型）；生产可替换 PostgreSQL；
- 文件存储：本地 `data/uploads`；生产可替换对象存储；
- 可选模型服务：千问 DashScope、DeepSeek、OpenAI，或内网 vLLM / SGLang / Ollama 的 OpenAI 兼容接口；
  通过 `LLM_PROVIDER` 预设切换（qwen / deepseek / openai / custom / auto），只填对应 key 即可；
  未配置模型时系统进入离线模式：问答为原文摘录、预审为规则检查、趋势为规则统计；
- 可选嵌入服务（检索用）：本地 sentence-transformers 模型，或内网 OpenAI 兼容 `/embeddings` 接口；未配置时自动使用纯 TF-IDF，功能不受影响；
- PDF 解析依赖：Poppler `pdftotext`。

### 2.2 客户端

- 浏览器：Chrome / Edge / Safari 等现代浏览器；
- 分辨率：建议 1440×900 及以上；
- 3D 趋势图需要 WebGL；不支持时自动降级为 2D。

### 2.3 开发环境

- Python 3.13、FastAPI 0.161、Uvicorn 0.54、scikit-learn 1.7、numpy 2.3、jieba 0.42；
- Node.js 22、React 19、TypeScript 5.8、Vite 6、ECharts 5.6、ECharts GL 2.0、Framer Motion 12。

## 3. 主要功能

### 3.1 文档管理

- 上传 DOCX / PDF / TXT / MD；
- 自动识别标题、年份、资料类型（本子/政策/文献/其他）；
- 解析正文、表格、页码（PDF）；
- 分块建立检索索引（TF-IDF 基线，可选叠加向量），保留章节/页码；
- 支持删除文档及索引。

### 3.2 智能查重

- 选择一份待查本子；
- 与已入库文档做段落级相似度比对；
- 输出相似文档、最高相似度、并排原文证据；
- 区分“高相似/关注/低相似”；
- 明确提示：相似度不等于抄袭，须人工复核。

### 3.3 专家库与专家匹配

- 专家 CSV 导入；
- 专家字段：姓名、单位、职称、学科、研究方向、代表性成果、回避单位、回避人员、在研项目数、是否可评审；
- 不使用性别、年龄等敏感属性；
- 硬约束：不可评审、在研项目数达上限、同单位、回避单位、回避人员；
- 匹配评分：方向语义相似度 + 关键词命中 + 学科匹配 - 负载惩罚；
- 输出相对匹配度、匹配理由、在研负载、排除原因及原名命中依据；
- 单位名仅统一排版空白、全半角字符与括号，保留英文词间空格及括号内容；不推断简称、别名或上下级关系；
- 缺申报单位或负责人时独立提示相应回避约束未生效，页面与导出均保留警告；
- 排除原因可展开查看。

### 3.4 查重+专家匹配一体化

- 同一页面选择本子，一次运行同时完成查重与专家匹配；
- 顶部展示最高相似度、查重命中、候选专家、排除专家；
- 一键导出 Markdown 结果；
- 对应课题考核指标“智能查重、专家匹配一体化工具”。

### 3.5 登录与角色

- 账号密码登录（PBKDF2 加盐哈希存储），会话以 HttpOnly Cookie 保持 7 天；
- 演示账号仅在本机监听时自动创建；支持用户自助修改密码（改密后所有旧会话失效）；
- 四类角色：管理员（全部功能 + 用户管理）、科研管理（上传/删除/导入/推送）、评审专家（问答/预审/查重匹配）、访客（只读演示）；
- 后端统一拦截接口请求，写操作按角色校验；前端按角色显示操作入口；
- 管理员可在"用户管理"页创建账号；演示账号仅限内网验证。

### 3.6 辅助功能

- 科研诚信 RAG 问答：带原文引用的多轮问答，检索支持向量与词面双通道；
- 本子预审：形式完整性、诚信与规范、语义查重、政策合规提示、风险等级、问题清单；
  未启用模型时报告附「能力边界说明」，逐条标明规则做不到的事项（语义归纳、版本时效、改写型重复）；
- 历史沿革：多年文献趋势、主题热度、年度发文量、3D/2D 图表、代表文献；3D 支持暂停/继续旋转，离屏与后台暂停，遵循系统减少动态效果；
- 工作台：按角色组织入口，提供资料概况与上传/预审快捷操作；首访纸页展卷、引用循证强调及预审结果“待人工复核”落款；手机端压缩重复介绍与指标卡排版，减少动态效果时静态呈现；
- 千问/离线双模式。

## 4. 操作流程

### 4.1 启动

```bash
./run.sh    # 自动探测 PYTHON / 项目 .venv / conda·Anaconda / 系统 python3，并补齐依赖
```

浏览器打开 `http://127.0.0.1:8010`。

### 4.2 上传本子

1. 点击右上角“上传文档”；
2. 选择 DOCX/PDF；
3. 资料类型选“本子/申报书”；
4. 点击“开始解析”，等待索引完成。

### 4.3 运行查重+专家匹配

1. 左侧导航进入“查重匹配”；
2. 在“待查本子”下拉框选择文档；
3. 点击“运行一体化检查”；
4. 查看左侧“语义查重”和右侧“专家匹配”；
5. 展开“已排除”查看负载/回避/不可评审原因；
6. 点击“导出结果”生成 Markdown 报告。

### 4.4 专家库维护

1. 在“专家库”区域点击“下载 CSV 模板”；
2. 按模板填写专家信息；
3. 点击“导入专家 CSV”；
4. 导入后重新运行一体化检查；
5. 演示专家可通过“移除演示专家”删除。

### 4.5 查重阈值说明

- 相似度 ≥ 0.55：高相似，建议人工重点复核；
- 0.30–0.55：需关注；
- < 0.30：低相似；
- 阈值需在真实历史本子库上校准，当前为原型默认值。

## 5. 输入输出

### 5.1 输入

- 申报书：DOCX、PDF、TXT、MD；
- 专家数据：CSV；
- 可选：政策文件、历史本子、文献 CSV；
- 可选：千问接口配置（环境变量）。

### 5.2 输出

- 查重结果：相似文档、相似度、并排证据；
- 专家匹配：候选专家、相对匹配度、匹配理由、排除原因；
- 导出报告：Markdown；
- 预审报告：Markdown/打印 PDF（辅助功能）。

## 7. 技术特点

1. **一体化**：查重与专家匹配在同一任务、同一页面完成，结果合并导出；
2. **证据可追溯**：查重展示本子/比对文档的原文片段；问答带页码/章节引用；
3. **可解释匹配**：给出方向命中、学科、代表成果、在研负载、回避检查等理由；
4. **约束前置**：先做可用性、负载、同单位、回避单位/人员过滤，再做语义排序；
5. **敏感属性最小化**：专家库不采集性别、年龄等与评审能力无关的属性；
6. **外挂式部署**：独立工作台，不修改现有科技管理系统；可后续通过只读 API/SSO 接入；
7. **离线可用**：未配置千问时使用检索式回答；配置千问后增强生成。

## 8. 边界与注意事项

- 查重相似度不等于抄袭，不自动认定重复申报；
- 专家匹配不替代专家抽取、回避审查和行政审批；
- 查重固定使用字符 n-gram TF-IDF（查重看的是字面重合，向量会把“主题相近但无重复”判成高相似）；问答检索已接入向量，混合检索与重排待做；
- 当前专家库为演示数据；真实专家库需授权导入；
- 扫描版 PDF 暂未启用 OCR；
- 原型内置账号密码登录与四角色（见 3.5）；生产部署建议替换为厅统一身份认证（SSO），并沿用同一角色模型；
- 演示文献、演示专家为合成数据，不能用于真实研究结论。

## 10. 持续验证

项目附带 36 项真实浏览器回归，与后端 123 个参数化展开用例共同验证。覆盖四角色、资料上传与导入、问答引用、预审/匹配下载、趋势降级与空库、手机导航及错误恢复。测试使用合成数据和独立临时库，不依赖真实模型；CI 随 push/PR 运行并保留失败证据。操作命令与范围见 `frontend/e2e/README.md`。自动化不能替代真实材料评估、人工页面审查及真机兼容性验证。

页面切换提供“翻卷入页”：标题立即显示，薄纸边展开、栏目卷标滑入，约450ms内纸边收拢并保留卷标；每次进入/返回重播，同页操作不重播。正文始终可见，手机端减幅并在导航抽屉收起后播放，系统减少动态效果时保持静态，不妨碍页面操作。
