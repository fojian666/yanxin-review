# 研信智评 · 科研诚信 RAG 智能评审助手（React + FastAPI）

面向江苏省自然资源科研管理场景的本地可运行原型：上传本子/政策/文献，做**带原文引用的问答**、**本子预审**和**多年文献趋势分析**。

- 前端：React 19 + TypeScript + Vite + ECharts / ECharts GL（3D 趋势图）
- 后端：FastAPI + Uvicorn + Pydantic（OpenAPI 文档 `/docs`）
- RAG：DOCX/PDF 解析 + 结构分块 + TF-IDF 检索 + 千问/离线双模式
- 部署：不侵入现有科技管理系统，独立工作台，内网可运行
- 安全：威胁模型、认证/授权/出口门禁/文件防护与部署检查清单见 `SECURITY.md`
- 设计：设计 token、字体/色彩、组件状态、动效与无障碍契约见 `DESIGN.md`

## 2. 登录与角色

系统内置账号密码登录（原型方案）与四类角色；正式部署时替换为厅统一身份认证（SSO/OIDC），角色模型沿用。

**演示账号**（首次启动自动创建，密码统一 `yanxin2026`，仅限内网验证）：

| 账号 | 角色 | 权限 |
|---|---|---|
| `admin` | 管理员 | 全部功能 + 用户管理（`/admin` 创建账号） |
| `manager` | 科研管理 | 上传/删除文档、导入文献与专家、移除演示数据、外部推送 `/api/ingest/*` |
| `reviewer` | 评审专家 | 问答、预审、查重匹配、文献趋势、知识图谱；文档中心只读 |
| `viewer` | 访客 | 问答与文献趋势（只读演示） |

- 演示账号**仅在本机监听（127.0.0.1）时自动创建**；对外监听默认不创建，确需演示设 `SEED_DEMO_USERS=1` 并用 `DEMO_USER_PASSWORD` 指定强密码（留空则生成随机密码打印到日志）；
- 登录后可在“用户管理”页自助改密（`POST /api/auth/password`，改密后所有旧会话失效）；
- 登录成功后显示短暂“正在进入评审工作台”过渡，落地 `/welcome` 欢迎页；刷新与会话恢复不重复播放；
- 登录失败限速：同一用户名+IP 连续失败 5 次（窗口 300 秒）返回 429，可配 `LOGIN_MAX_FAILURES` / `LOGIN_WINDOW_SECONDS`；限速分桶键为定长摘要，登录入参另有长度上限（用户名 ≤64、口令 ≤256，超出 422）；
- **数据不出内网（代码级强制）**：LLM 端点仅放行回环/内网/内网域名，公网 DashScope/OpenAI 默认阻止（健康检查显示“公网出口已阻止”），确需使用须显式设 `ALLOW_EXTERNAL_LLM=1`；
- 专家库读取（`GET /api/experts`）限评审专家/科研管理/管理员——访客不可见回避关系与负载画像；
- Qwen3 思考模式：`LLM_ENABLE_THINKING` 留空不发送（兼容旧服务）、设 0 显式关闭（避免只返回思考内容）、设 1 开启；
- 解析边界：单文件 30MB、DOCX 解压总量 120MB、PDF 默认只解析前 2000 页（`MAX_PDF_PAGES` 可调，0 为不限）；HTTPS 部署设 `COOKIE_SECURE=1` 强制会话 Cookie 加密传输；

- 会话：登录后签发 HttpOnly Cookie（7 天有效）；任何接口返回 401 时前端自动回到登录页。
- 权限双层执行：前端按角色隐藏按钮，后端中间件统一拦截 `/api/*` 并对写操作按角色返回 403。
- 密码以 PBKDF2 加盐哈希存储；`admin` 可在“用户管理”页创建正式账号。

## 3. 快速启动

环境要求：Python 3.10+；PDF 解析需要 `pdftotext`（macOS `brew install poppler`，Ubuntu `apt install poppler-utils`）。如果 `frontend/dist` 已存在，运行时不依赖 Node；重新构建前端需要 Node 20+。

```bash
cd "课题申报：科研诚信驱动的自然资源科研全周期智慧治理与大模型协同关键技术研究"

cp .env.example .env        # 可选：填入千问配置
./run.sh                    # 自动选择可用解释器，缺依赖时自动安装
```

打开 <http://127.0.0.1:8010>；接口文档 <http://127.0.0.1:8010/docs>。

依赖由 `run.sh` 在所选解释器上自动安装。如果本机没有可用环境（例如 Homebrew Python 受 PEP 668 限制），先 `python3 -m venv .venv` 再运行 `./run.sh`——它会优先使用项目 `.venv`。

`run.sh` 做的事情：

1. 自动选择解释器（显式 `PYTHON` > 项目 `.venv` > conda/Anaconda 已知路径 > 系统 `python3`，取首个能导入依赖者）并检查依赖；
2. 如果 `frontend/dist` 不存在，执行 `cd frontend && npm install && npm run build`；
3. 用 Uvicorn 启动 FastAPI，并托管 React 构建产物。

首次启动会自动：

1. 创建 `data/app.db` 与 `data/uploads/`；
2. 演示账号种子（仅本机监听时创建，见“登录与角色”）；课题申请书含个人信息，**默认不再自动入库**——需要示例本子时在 `.env` 显式设 `SEED_SAMPLE_DOC=1` 并把文件放入项目根目录后重启；
3. 写入 42 篇合成演示文献，用于验证趋势功能；
4. 写入 12 位合成演示专家（`is_sample=1`），用于验证专家匹配。

不需要演示数据时，在 `.env` 中设置 `SEED_SAMPLE_DOC=0`、`SEED_DEMO_PAPERS=0`，或在界面中删除示例本子、点击“移除演示文献”；演示专家无环境变量开关、首次启动会无条件写入，可在“查重匹配”页点击“移除演示专家”一键清理。

**政策语料（真实公文）不是演示数据，运行时不联网自取**：`./run.sh` 启动时会自动导入一次（幂等、失败不阻断）；直接用 `uvicorn` 起服务或改了快照后，手动跑一次：

```bash
python3 -m rag.corpus            # 把 corpus/ 下两部公开公文写入文档库（幂等）
python3 -m rag.corpus --list     # 只看清单、来源与入库状态，不写入文档
```

前提是仓库自带的 `corpus/policy/*.txt` 已就位（随仓库提供）。要重新抓取或换机器重抓：

```bash
python3 tools/fetch_corpus.py            # 抓取 → 覆盖 corpus/policy/ 与 corpus/sources.json
python3 tools/fetch_corpus.py --check    # 不联网，只校验快照与清单 sha256 是否一致
```

手动抓取只接受固定政府来源的 HTTPS，校验证书并拒绝重定向；失败时保留原快照和已有清单，不回退 HTTP。当前江苏转载渠道的 HTTPS 证书在本机校验失败，重新抓取会明确报错，随库交付的快照仍可离线使用。SHA256 校验用于发现快照改动，不是政府签名或来源认证；更新后仍需核对发布机关及正文。`rag.corpus --force` 只重建清单中同来源政策，不删除已移出清单的历史政策，避免破坏已有引用。

## 5. 接入大模型

`LLM_PROVIDER` 选供应商，其余变量按需覆盖。预设只填 key 就能用，不用记 base_url 和模型名：

| `LLM_PROVIDER` | 端点 | 默认模型 | 需要的 key |
|---|---|---|---|
| `qwen` | DashScope 兼容模式 | `qwen-plus` | `QWEN_API_KEY` / `DASHSCOPE_API_KEY` |
| `deepseek` | `api.deepseek.com/v1` | `deepseek-flash` | `DEEPSEEK_API_KEY` |
| `openai` | `api.openai.com/v1` | `gpt-4o-mini` | `OPENAI_API_KEY` |
| `custom` | `LLM_BASE_URL`（内网 vLLM / SGLang / Ollama） | `LLM_MODEL` | 可不填，内网通常不校验 |
| `auto`（默认） | 按已有 key 推断，兼容旧配置 | — | — |

DeepSeek 预设仅使用自身密钥或显式 `LLM_API_KEY`，不会回落使用千问密钥。OpenAI 预设默认不发送千问/DeepSeek 思考扩展参数；显式 `LLM_THINKING_STYLE=none` 可覆盖所有预设，其他显式方言同样优先。

```bash
# 千问（留好位置，将来填 key 即用）
LLM_PROVIDER=qwen
QWEN_API_KEY=sk-xxxxxxxx

# DeepSeek
LLM_PROVIDER=deepseek
DEEPSEEK_API_KEY=sk-xxxxxxxx
ALLOW_EXTERNAL_LLM=1               # 公网端点默认被拦

# 内网自建（推荐用于真实评审材料）
LLM_PROVIDER=custom
LLM_BASE_URL=http://10.0.0.10:8000/v1
LLM_MODEL=Qwen3-32B
```

任何预设都可以用 `LLM_MODEL` / `LLM_BASE_URL` 覆盖。**别用旧的 `QWEN_BASE_URL` 覆盖**：
预设模式下它不参与，就是为了防止留着 A 家的地址却换成 B 家的 key。

两个与模型有关的行为：

- **思考模式**：DeepSeek 默认开思考，预审要 JSON 时思考会把 `max_tokens` 吃光、正文为空。
  代码按 `style` 发不同参数（DeepSeek 发 `thinking.type=disabled`，千问发 `enable_thinking`），
  `LLM_ENABLE_THINKING=0` 可显式关掉，`LLM_THINKING_STYLE` 可强制指定方言。
- **没有模型时的兜底**：问答退化为按关键词与章节挑句的原文摘录，预审退化为规则引擎（形式完整性、
  诚信表述、字面查重、政策条款提示），趋势退化为规则统计。三者都会在结果里写明「只到这一步」——
  预审报告的 `limitations` 会逐条列出规则做不到的事（语义归纳、版本时效、改写型重复），
  前端显示在结论下方。**这时不会假装做过语义判断。**

顶栏显示当前配置的供应商与模型（如 `DeepSeek · deepseek-flash`、`千问 / DashScope · qwen-plus`）；手机端显示在标题说明下方。每条回答与预审报告另存实际生成来源，报告 Markdown 导出同步保留；调用失败显示“已回退离线摘录/规则预审”，中途断线保留已输出内容的模型来源并标为“生成中断”。旧结果缺少来源记录时不推断供应商。

旧 `QWEN_*` 接口继续可用：自动配置识别官方 DeepSeek 与 DashScope 端点后显示对应名称，自建兼容端点保持通用名称；不改变密钥选择或出口授权。

**注意**：公网端点（DashScope / DeepSeek / OpenAI）意味着上传的评审材料会离开内网；真实评审场景请使用内网模型或先完成数据合规审批。

## 6. 文档与文献数据

### 文档上传

- 支持：`.docx`、`.pdf`、`.txt`、`.md`；单文件 ≤ 30MB。
- 扫描版 PDF 暂未启用 OCR：`pdftotext` 提取不到文本时会提示，需先 OCR 或换可复制文本的 PDF。
- 资料类型：本子/申报书、政策/管理办法、文献/论文、其他；也可自动判断。
- 上传“文献”类型时，会同步写入趋势分析的文献库。

### 专家 CSV

“查重匹配 → 专家库 → 下载 CSV 模板”，列：

```csv
姓名,单位,职称,学科,研究方向,代表性成果,回避单位,回避人员,在研项目数,是否可评审
示例专家A,示例大学A,教授,科研管理,科研诚信;科技政策,主持科研诚信相关课题（示例）,示例大学B,,1,是
```

- 研究方向、回避单位、回避人员可用 `;`、`,`、`、` 分隔；
- 在研项目数达到 5 视为负载已满；
- 不采集、不使用性别、年龄等敏感属性；
- 重复导入相同专家（姓名+单位一致）自动跳过。

### 文献 CSV

“文档中心 → 文献数据 → 下载 CSV 模板”，列名支持中英文：

```csv
标题,年份,作者,期刊,摘要,关键词
面向自然资源科研诚信的风险预警研究,2024,张三,示例期刊,摘要内容,科研诚信;风险预警
```

也支持 `title,year,authors,venue,abstract,keywords`。关键词用 `;`、`,`、`、` 分隔均可。重复导入相同文献（标题+年份一致）会自动跳过，接口返回 `count`（新增）与 `skipped`（跳过）。

### 外部系统推送（预留接口）

当前文献/专家/示例本子均为**演示数据**。真实数据接入已预留三种路径：

| 路径 | 状态 | 说明 |
|---|---|---|
| CSV 导入 | 已有 | 界面人工批量导入（本文档上文） |
| JSON 推送 `/api/ingest/*` | 已实现 | 外部系统直接推送，幂等去重，可重放 |
| 只读 API 拉取 | 规划中 | 对接省厅科技管理系统（实施方案 §7 数据外挂） |

- `POST /api/ingest/experts`：body `{"experts": [{name, institution, ..., research_areas: [], workload, available}]}`，同名同单位跳过；
- `POST /api/ingest/papers`：body `{"papers": [{title, year, authors, venue, abstract, keywords: []}]}`，同题同年跳过；
- `GET /api/ingest/schema`：自描述契约，含字段 JSON Schema、鉴权方式与预留实体，供对接方自查；
- 鉴权：`.env` 设置 `INGEST_TOKEN` 后，推送接口要求请求头 `X-INGEST-Token` 匹配；未设置时本机演示不鉴权；
- **预留未启用**：项目/课题（ProjectRecord）、诚信记录（IntegrityRecord）、政策版本（PolicyMeta）的结构已在 `rag/schemas.py` 冻结并通过 `/api/ingest/schema` 公开，存储与接收端点待接入真实数据源后启用。

### 公开政策语料（真实公文）

库里除合成演示数据外，还带两部**真实政府公开文件**，用于让“政策合规”检查有真实条款可引：

| 文件 | 文号 | 发布机关 |
|---|---|---|
| 科研失信行为调查处理规则 | 国科发监〔2022〕221号 | 科技部等二十二部门 |

## 7. 当前实现方式

### 问答链路

1. 解析：DOCX 用 Word XML（含脚注/尾注）；PDF 用 `pdftotext`；文本按段落/章节切分。
2. 分块：按章节标题、段落、句边界切分，块大小约 700 字，重叠 100 字并对齐到句边界；保留页码/章节。
3. 检索：分为 TF-IDF 与向量两层（见下一节），按可用后端自动选择；返回 Top K 片段。
4. 生成：配置千问时，将编号资料 + 问题 + 最近对话发给 Qwen；未配置时使用摘录式回答。
5. 引用：回答中的 `[n]` 与检索片段一一对应；前端右侧面板展示原文和相似度。

### 检索策略（TF-IDF 与向量）

两套打分并存，对外接口不变：

- **TF-IDF（字符 2–4 gram）**：始终构建。零依赖、可离线，是基线，也是向量不可用时的回落；
- **向量（embedding）**：可用时接管检索。词面不重合也能命中——问“调查取证时禁止哪些手段”，TF-IDF 排第 4，向量排第 1。

后端由 `EMBED_BACKEND` 选择：`local`（进程内 sentence-transformers，模型放 `models/`，不进仓库）、`api`（OpenAI 兼容 `/embeddings`，默认 `BAAI/bge-m3`）、`none`（纯 TF-IDF）；默认 `auto` 按 本地 → API → none 取第一个可用的。

安全口径与 LLM 一致：公网端点默认拦住，必须显式 `ALLOW_EXTERNAL_EMBED=1` 才放行（本机 `127.0.0.1` 不受限）。**真实评审材料应使用 `local` 或内网端点**，见 `SECURITY.md` §5。

向量按「单条文本 + 模型」哈希缓存在 `data/embed_cache/`：新增一份文档只补算它自己的分块，不会整库重算。实测 32 条冷启动 0.6s（2 次批量请求），命中缓存 0.1ms；单次检索向量 37ms、TF-IDF 0.8ms。

阈值要分开设：TF-IDF 的无关文本余弦接近 0，而向量对无关中文段落也有 0.3–0.4 的底噪。本语料实测——「金星的地质构造」「如何做红烧肉」这类完全无关的问题最高分 0.34–0.44，领域内问题 0.48–0.74——所以：

- 结果下限 `EMBED_MIN_SCORE=0.45`（低于此值不出结果，等于「没有相关资料」，问答会据此说明资料不足）；
- 政策引用下限 `0.58`：写进报告要引条款，要求比普通问答更严；
- 证据面板的相似度条按后端分档映射（向量 `0.45–0.80` 铺满整条，TF-IDF 仍按 `×240`），否则向量分值一律顶到 99%，条形读不出强弱。

同一批 14 个政策问题（答案按原文关键句定位，不靠人工挑）的召回对比，用 `python3 -m tools.eval_retrieval` 可复跑：

| 模式 | 命中@3 | 命中@1 | MRR |
|---|---|---|---|
| TF-IDF | 71.4% | 57.1% | 0.631 |
| 向量 | **92.9%** | **64.3%** | **0.762** |

提升集中在“问法与条文用词不一致”的问题上（如“项目信用管理涵盖哪些环节”“调查取证禁止手段”）；两边都命中的题，向量多数仍排第 1，代价是个别词面强匹配的题（论文代写代投）向量退到第 2。仍有 1 题两种模式都未命中：答案在江苏省办法、但 221 号文的“处理”章节在词面上更近，这是单向量召回的已知短板，后续靠混合检索（词面 + 向量）补。

**政策不进入查重候选池**（在候选截断前排除），仍用于问答和预审政策引用。

**查重不走向量。** `similarity_between_docs()` 固定用 TF-IDF：查重要看的是字面重合，向量会把“主题相近但没有重复”判成高相似，反而制造误报。

### 本子预审

模型模式始终保留系统检索生成的「文件＋章＋条」政策引用、可展开原文与人工核对提示，以及真实查重结果；模型不能用概述覆盖这两类证据。

- 规则检查：章节完整性、科研诚信/数据安全/伦理/知识产权表述、参考文献、文档长度。
- 文本查重：对已入库文档做段落级 TF-IDF 相似度比对，给出相似段落和相似度；相似 ≠ 抄袭，必须人工判断。
- 政策引用：检索已入库政策文件中的相关条款作为提示；随库公开政策可通过 `run.sh` 自动导入，引用内容与适用性须人工核对。
- 千问配置后，由模型生成结构化 JSON 预审意见；解析失败自动回退到规则预审。
- 不输出总分、排名、立项结论；报告页脚带免责声明。

### 历史沿革 / 文献趋势

1. 用主题词在文献库中做相关性筛选（标题/关键词/摘要命中 + TF-IDF）。
2. 按年份统计发文量和主题词出现次数。
3. 生成 3D 年度发文量柱状图、3D 主题热度矩阵；可切 2D 折线/柱状图。
4. 生成主题热度、年度高频主题、代表性文献和趋势摘要；配置千问后由模型生成 3–5 条趋势研判。

### 动效规范

- 字体三层分工：标题/品牌用宋体，文案（欢迎语、回答、研判、证据原文、免责声明）用楷体（多平台回退），界面控件/数据用黑体；文案块统一 `letter-spacing .02em`、行高 1.8+；
- 统一缓动 `cubic-bezier(.22, 1, .36, 1)`；页面进入 220ms、退出 100ms，按钮反馈 150ms；
- 入场位移不超过 10px，hover 抬升 1–2px，避免大幅缩放/旋转；
- 导航使用共享布局滑块；3D/2D 切换交叉淡入，避免图表硬切；
- 换主题时 KPI 数值滚动/字符串淡入、趋势摘要与年度主题重新入场、文献卡片错峰、图表数据过渡；
- 3D 自动旋转速度 2，可手动暂停/继续；拖拽结束静置 4s 后恢复，离屏、后台与减少动态效果下暂停；
- 侧边栏收起/展开用可取消的 rAF 补间（220ms 缓出，只动 transform）；图表在容器尺寸变化时即时 resize，避免多重补间；
- 分析请求做 280ms 防抖：快速响应不闪 loading 遮罩，慢请求才显示“分析中…”；按钮不使用持续旋转图标；
- 每次分析 KPI 四张卡整体重新入场，年份跨度等不变值也有反馈；
- 支持 `prefers-reduced-motion`：关闭自动旋转、CSS 动画与 Framer 位移动画；
- 登录页动态地形：等高线 `pathLength` 描边生长 + 虚线流动 + 远/近双层漂移（指针视差 `--px/--py`）+ 扫描带 + 纸纹颗粒；入场只用 transform，保证任何一帧内容都可见；
- 状态变化动效（Framer `AnimatePresence`）：表格行删除退出、匹配面板空↔结果切换、上传弹窗文件芯片切换、KPI 数值变化 480ms 闪光；
- 登录成功过渡：深色印章 + 扫描线约 280ms（reduced-motion 即时切换），无假进度数字；仅真实登录触发，刷新不重复；
- 全局尺度：正文 15px、表格 13.5px、标签 12px、控件高 40px、侧栏 264px（折叠 84px）、主区留白 32–48px；≤1400px 表格自动紧凑；
- 路由级 code splitting，3D 图表按需加载。

### 交互边界

- 侧边栏可收起为图标栏（状态记忆于本地，窄屏默认收起）；≤680px 改为抽屉导航（遮罩、焦点陷阱、ESC 关闭、路由切换自动收起）；
- 无障碍：全局「跳到主要内容」skip link、路由切换焦点移交主区、图表 `role="img"` 文本摘要；焦点环与辅助文字对比度实测满足 WCAG AA（含深色侧栏与登录页脚）；
- 高度适配：聊天与证据面板按 `100dvh` 收缩并只做面板内滚动；弹窗/预审栏内部滚动；≤620px 高时登录页隐藏装饰能力卡；375×560 下上传弹窗按钮仍可达；
- 侧边栏、顶栏、按钮、筛选、KPI、图表工具栏、表格操作不可选中/拖动；
- 正文（问答、证据、摘要、论文信息、表格内容、预审报告）保留选中与复制；
- 导航链接无下划线，禁用原生链接拖拽；
- 固定滚动条槽（`scrollbar-gutter`），顶栏上传按钮不随页面高度/滚动条变化而左右移动；
- 3D 图表仍支持拖拽旋转；滚轮不再缩放图表，而是正常滚动页面。

### 3D 图表实现

- `echarts` 5.x + `echarts-gl` 2.x；
- `bar3D` 年度柱状图：自动旋转、拖拽旋转、光照与阴影；**滚轮缩放已关闭，滚轮用于页面滚动**；
- `bar3D` 主题矩阵：主题 × 年份 × 文献数；
- `postEffect` 开启 Bloom/SSAO，增强立体层次；
- 顶部“3D / 2D”切换；浏览器无 WebGL 时自动使用 2D 并给出提示；
- KPI 数字滚动、卡片入场、报告风险环等使用 Framer Motion / CSS 动画。

`tests/test_robustness.py` 覆盖的加固点：

- **空文献库趋势**：`papers` 为空时返回空趋势而非在 TF-IDF 处崩溃。
- **SPA 路径穿越**：`/../` 等越界路径一律 404，绝不返回 `frontend/dist` 之外的文件。
- **错误信息不外泄**：未捕获异常统一返回“服务器内部错误”，响应体不含内部细节（如密码、堆栈）。
- **`top_k` 边界**：`ToolCheckRequest.top_k` 限定 `1–20`，越界返回 422。
- **SQLite 并发**：连接启用 `WAL` + `busy_timeout=5000`，缓解读写并发锁冲突。
- **超长文档截断**：解析后统一执行 `MAX_CONTENT_CHARS`（默认 6 万字）截断并给出 warning，避免超大文件撑爆分块/索引（已用 8 万字 TXT 端到端验证：截断至 6 万字、86 块、提示“文档过长”）。

前端健壮性（经 `tsc --noEmit` + 构建 + 跨路由冒烟验证，无控制台错误）：

- **请求超时**：`api.ts` 的 `request()` 加 `AbortController`（默认 60s），后端卡死时 UI 不再永久挂起，提示“请求超时”；`fetch` 网络异常统一提示“网络错误，无法连接到服务器”。SSE 流式接口不设硬超时（长连接），仅对建连失败做友好提示。
- **ErrorBoundary**：路由外层包裹 `components/ErrorBoundary.tsx`，单页渲染崩溃时显示兜底卡片（重试 / 返回问答），不再整站白屏；按 `pathname` 自动重置。

## 12. 当前边界与下一步

**边界**

- 单机演示版：默认只监听 `127.0.0.1`；内网其他机器访问设 `HOST=0.0.0.0` 前，应先配置强口令（`SEED_DEMO_USERS` + `DEMO_USER_PASSWORD`）与防火墙。已有账号密码登录与四角色权限矩阵，SSO/OIDC 待接。
- 当前使用 Uvicorn 开发模式；生产部署请配置多 worker、Nginx、HTTPS、日志与进程守护。
- 无 OCR；扫描件需先转文本。
- 检索默认 TF-IDF，配置嵌入后端后走向量；但**没有向量库**（矩阵在内存点积，几千块量级足够），也没有混合检索与重排；嵌入模型尚未本地化，公网端点需显式授权。
- 3D 图表依赖 WebGL；无 WebGL 自动降级 2D。
- 已做路由级 code splitting：首屏 JS 约 423KB；3D 趋势页按需加载约 1.66MB（ECharts GL 占比较大）。
- 预审为规则 + 可选千问，不替代专家评审；查重结果需人工复核。
- 政策库当前只有两部公开公文（科技部调查处理规则、江苏项目信用办法），覆盖面有限；条款级比对只给“可能相关条款”，**版本时效（生效/失效/被替代）尚未建模**（`rag/schemas.py` 的 `PolicyMeta` 字段已冻结、存储未启用），引用前须人工核对适用版本。
- 专家匹配目前是原型：示例专家为合成数据；真实专家库、回避关系和负载数据需接入现有系统或 CSV 授权导入。
- 正式研究报告、省厅试点验证报告、论文、软著尚未提交；`交付材料/` 中是初稿/模板，不能当作已验收成果。
- 演示文献为合成数据，不能用于真实研究结论。

**建议下一步**

1. 配置真实 Qwen（内网优先），用 20–30 份真实本子做评测集，校准检索阈值和预审口径。
2. 嵌入模型本地化（bge-m3 落内网）+ 词面/向量混合检索 + 重排；语料上到十万块再评估向量库（Milvus）。
3. 导入真实政策库（含生效/失效日期），启用条款级合规审查。
4. 接入现有科技管理系统：只读 API/视图、SSO、预审任务回写。
5. 生产化：OCR、权限、审计、加密、等保、模型服务监控。

专家单位回避只统一排版空白、全半角字符及括号，保留英文词间空格与括号内容；不推断简称、别名或隶属关系。页面和 Markdown 导出均保留双方原名、命中依据及缺失申报信息警告。当前回归包含 134 个测试函数，参数化展开为 147 个用例。

生成来源 API 契约：`/api/chat` 和 `/api/review` 返回增量字段 `generation`（`provider`、`label`、`model`、`status`）；SSE 在首段正文之前发 `generation` 事件，`done` 带最终来源。`status` 为 `complete` / `fallback` / `interrupted`。保留旧 `mode="qwen"` 表示模型路径以兼容客户端，不以它判断实际供应商；来源快照不含密钥或接口地址。流未收到 `done` 即结束按中断处理。

智能问答输入框上方可选择模型和推理强度，每组单选。系统默认沿用现有配置，离线摘录不调用模型；额外模型仅使用对应供应商自身密钥和官方端点，受公网出口门禁控制。DeepSeek 与受支持的千问模型提供关闭思考、低、高、最高；不支持的模型只提供系统默认。设置只影响下一条问答，生成中锁定，切页保留、退出登录或刷新重置；预审和趋势仍用后台配置。高强度可能增加等待和用量。`/api/chat` 与 `/api/chat/stream` 接受可选 `model` 和 `strength`（省略兼容旧客户端），后端校验白名单，来源快照包含实际强度。

所有受保护路由共享同一个单页工作区外壳。工作台顶部只保留一个当前卷宗入口，预审与查重始终读取该选择；进入问答时可用该卷宗作为初始范围，问答仍可多选资料。知识图谱以静态科研治理实体与关系提供检索、邻接和路径推演；文档中心以目录和书页正文呈现当前文档库，并保留上传、删除、筛选、问答、预审和文献 CSV 管理。选择仅保存在当前登录会话的页面状态，刷新后重置；政策或文献不会覆盖当前申报书。手机任务态压缩卷宗上下文与功能索引，把首屏留给当前操作；问答可切换证据面板，点击引用自动定位并转移焦点。预审报告在桌面独立滚动，打印时展开完整内容；专家库和代表性文献按需展开。
